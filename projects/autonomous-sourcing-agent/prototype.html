Explain the difference

Supplier B is $12 cheaper per chair ($600 over 50 chairs), and its sample delivery is earlier. The example assumes both satisfy mandatory criteria. The source product presentation describes a 6.2-point weighted-score lead; the simplified walkthrough does not reproduce the full score calculation.

This comparison is sample data, not a real supplier quotation or live agent output. A production implementation would link each figure to a source response and retain exclusions and scoring configuration.
